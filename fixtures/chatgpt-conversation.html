A palindrome number is a number that reads the same from left to right and from right to left.

Simple trick: Reverse the number. If the reversed number is the same as the original, it's a palindrome!

2. How to check a palindrome number in Python

Let's use 121 as an example.

Python
num = 121
original = num
reverse = 0

while num > 0:
digit = num % 10
reverse = reverse * 10 + digit
num = num // 10

if original == reverse:
print("Palindrome")
else:
print("Not a palindrome")

Output:

Plain text
Palindrome

3. Understand the logic step by step

We start with:

  • num = 121

  • reverse = 0

The loop extracts the last digit using % 10 and adds it to the reversed number.

Step 1

Digit = 1

reverse = 0 × 10 + 1 = 1 \text{reverse} = 0 \times 10 + 1 = 1 reverse=0×10+1=1

Remove the last digit: 121 → 12

Step 2

Digit = 2

reverse = 1 × 10 + 2 = 12 \text{reverse} = 1 \times 10 + 2 = 12 reverse=1×10+2=12

Remove the last digit: 12 → 1

Step 3

Digit = 1

reverse = 12 × 10 + 1 = 121 \text{reverse} = 12 \times 10 + 1 = 121 reverse=12×10+1=121

Remove the last digit: 1 → 0. The loop ends.

Final comparison

121 = 121

Therefore, 121 is a palindrome number.

4. Remember these two operators

  • num % 10 → gets the last digit of a number.

    • Example: 123 % 10 = 3

  • num // 10 → removes the last digit.

    • Example: 123 // 10 = 12

In one line: A palindrome number is a number that remains the same when reversed.

2. Same palindrome program in four languages

Python — easiest to read

Python
n = 121
if str(n) == str(n)[::-1]:
print("Palindrome")
else:
print("Not Palindrome")

Uses string slicing to reverse the number.

C — good for fundamentals

C
#include <stdio.h>

int main() {
    int n = 121, temp = n, rev = 0;

    while (n > 0) {
        rev = rev * 10 + n % 10;
        n = n / 10;
    }

    if (temp == rev)
        printf("Palindrome");
    else
        printf("Not Palindrome");

    return 0;
}

Uses arithmetic to reverse the number.

Java — good for OOP and DSA

Java
class Main {
    public static void main(String[] args) {
        int n = 121, temp = n, rev = 0;

        while (n > 0) {
            rev = rev * 10 + n % 10;
            n /= 10;
        }

        System.out.println(
            temp == rev ? "Palindrome" : "Not Palindrome"
        );
    }
}

Similar logic to C, with a class and main method.

C++ — good for competitive programming

C++
#include <iostream>
using namespace std;

int main() {
    int n = 121, temp = n, rev = 0;

    while (n > 0) {
        rev = rev * 10 + n % 10;
        n /= 10;

    cout << (temp == rev
        ? "Palindrome" : "Not Palindrome");

Uses arithmetic and C++ output syntax.

3. Which language should you choose?

  • For absolute beginners: Python, because the syntax is simple.

  • For college exams and learning logic: Use the language prescribed in your course.

  • For DSA and placements: Java or C++ are both strong choices. Practise digit reversal using arithmetic, not just built-in shortcuts.

  • For AI/ML development: Python is the best starting choice because of its extensive AI ecosystem.

4. Important point for exams

If the question asks you to write a program to check a palindrome number, the arithmetic approach is often the better one to learn:

  1. Store the original number.

  2. Extract the last digit using % 10.

  3. Build the reverse using rev = rev * 10 + digit.

  4. Remove the last digit using // 10 in Python, or integer division in C, C++, and Java.

  5. Compare the reversed number with the original.

This teaches the actual programming logic and works without converting the number into a string.

My recommendation: Learn the arithmetic approach first, then learn the shorter Python string-slicing approach.
